## 적용 내용

현재 작업본 RC009의 본문·이름·UI·연표 번역과 한글 렌더러를 포함합니다. 본편의 8/16/22px 렌더링 규칙을 참고하고, 이미지 문자는 별도 경로로 처리했습니다. 타이틀과 메뉴, 하단 로고, 메뉴의 ver.2 간격을 수정했습니다. 한글 구두점 폭과 설명문 줄바꿈, 결정 표기 및 돌아가기 배치를 조정했습니다.

본문 1,798개 논리 번역과 추가 이름 424개를 기반으로 저장 필드 39,432개/41개 자원, 직접 Print 리다이렉트 389곳 및 내용 일치 복사 가드 536개를 적용했습니다. 중복된 물리 필드 수는 서로 다른 문장 수가 아닙니다. 이미지 문자 적용은 6개 자원/75개 물리 표시 영역입니다. M0855·M0856의 승인 문구와 개행을 유지했습니다.

## 검증 범위

원본 ISO와 최종 RC009의 SHA-256, ISO 역독, 원본→패치→RC009 전체 바이트 일치 및 배포 ZIP/체크섬을 검증했습니다. 설명 패널 175개의 정적 글리프·폭·하단 안내 겹침 검사에서 초과 0건을 확인했습니다.

**이번 RC009의 게임 실행·콜드부팅·SAVE/LOAD 검증은 NOT_RUN입니다.** 미전사 이미지·동영상 문자, 한글 이름 입력, PLAN 이름의 전체 표시 소비처 등 남은 항목이 있습니다. 전체 게임 번역 완료 또는 전체 화면 실행 검증을 뜻하지 않습니다. 사용자의 현재 상태 공개 요청으로 게시하며 기존 canonical=false/release_ready=false 검증 상태를 유지합니다.

## 적용 방법

릴리스 ZIP 전체를 풀고 일본판 **원본** ISO에 한 번 적용합니다. 본편이나 기존 한글 패치 ISO에는 적용하지 않습니다. macOS에서는 xdelta3를 준비한 뒤 다음과 같이 실행합니다.

```sh
zsh 적용.command '/원본/일본판.iso' '/결과/공략지령서_한글_1.0.iso'
```

다른 환경에서는 xdelta 도구로 `GIREN_KOURYAKU_PS2_KO_1.0.xdelta`를 적용하고 결과 체크섬을 확인하세요. 원본과 결과 크기는 모두 4,407,918,592 bytes입니다.
