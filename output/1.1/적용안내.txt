기동전사 건담 기렌의 야망 지온독립전쟁기 공략지령서 PS2 한국어 패치 ver.1.1

지원 원본: 일본판 공략지령서 SLPS-25212 (SLPS_252.12)
본편 또는 액시즈의 위협 ISO용 패치가 아닙니다.

결과 ISO 크기: 4,418,881,536 bytes
원본 SHA-256: 6fb2c79197954c4170155d42b35834e5ef9c808d71c09e4ccec430fc01be6758
결과 SHA-256: 605aa86b07cf829d700ce1ff80b42c44691cd572543de817a82819fdf1c31b58

일본판 원본에 한 번 적용하는 누적 패치입니다.
기존 한글 패치 ISO에는 중복 적용하지 마세요. 원본 ISO는 보존하세요.

macOS:
1. ZIP 전체를 같은 폴더에 풉니다.
2. xdelta3를 준비합니다. Homebrew: brew install xdelta
3. 터미널에서 실행합니다. 경로는 각자 파일 위치로 바꾸세요.
   zsh 적용.command '/원본/일본판.iso' '/결과/공략지령서_한글_1.1.iso'
   원본·패키지·결과 체크섬을 확인하며 기존 결과 파일은 덮어쓰지 않습니다.

Windows/Linux 또는 다른 xdelta 도구:
  xdelta3 -d -s "일본판원본.iso" "GIREN_KOURYAKU_PS2_KO_1.1.xdelta" "새결과.iso"
  원본과 결과의 SHA-256을 위 값과 대조하세요. 패치는 분할하지 않은 표준 VCDIFF입니다.

1.1에는 영상 자막과 로더/영상 목록 표시 수정, 퍼즐 렌더링 수정,
한글 이름 입력용 처리와 저장 목록 표시 보완, 고정 문구 추가 번역을 포함합니다.
실행 검수는 선택 영상 및 퍼즐 스테이지1에 한정하며, 전체 게임/전체 영상/저장·불러오기 전수 검수는 미완료입니다.
원래 영상에 박힌 일본어 문구와 작은 이미지 캡션 등 일부 보류 항목은 유지합니다.
