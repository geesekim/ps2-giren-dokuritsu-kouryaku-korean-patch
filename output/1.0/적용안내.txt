기동전사 건담 기렌의 야망 지온독립전쟁기 공략지령서 PS2 한국어 패치 ver.1.0

지원 원본: 일본판 공략지령서 SLPS-25212 (SLPS_252.12)
본편 또는 액시즈의 위협 ISO용 패치가 아닙니다.
원본 및 결과 ISO 크기: 4,407,918,592 bytes
원본 SHA-256: 6fb2c79197954c4170155d42b35834e5ef9c808d71c09e4ccec430fc01be6758
결과 SHA-256: 73ff13caed5a00044c414677ce4669da245fb4de1dfc7e1e6504c03b6b21d9c6

처음부터 일본판 원본에 한 번 적용하는 누적 패치입니다.
이전 한글 패치 ISO에 중복 적용하지 마세요. 원본 ISO는 보존하세요.

macOS:
1. ZIP 전체를 같은 폴더에 풉니다.
2. xdelta3를 준비합니다. Homebrew: brew install xdelta
3. 터미널에서 다음과 같이 실행합니다. 경로는 각자 파일 위치로 바꿉니다.
   zsh 적용.command '/원본/일본판.iso' '/결과/공략지령서_한글_1.0.iso'
   스크립트는 원본/패키지/결과 체크섬을 확인하며 기존 결과 파일을 덮어쓰지 않습니다.

Windows/Linux 또는 다른 xdelta 도구:
  xdelta3 -d -s "일본판원본.iso" "GIREN_KOURYAKU_PS2_KO_1.0.xdelta" "새결과.iso"
  원본과 결과의 SHA-256을 위 값과 대조하세요. 패치는 표준 VCDIFF이며 armor를 사용하지 않습니다.

현재 RC009의 번역·폰트·이미지·구두점·줄바꿈 수정 내용을 포함합니다.
정적 ISO 역독과 패치 전체 재적용 검증을 수행했습니다.
이 버전으로 게임/에뮬레이터를 실행한 런타임 검증 및 SAVE/LOAD 검증은 NOT_RUN입니다.
모든 화면·이미지·동영상의 번역 완료 또는 전체 게임 동작을 보증하는 상태가 아닙니다.
자세한 적용 범위와 남은 항목은 README 및 runtime-summary.json을 참고하세요.
